# 🤖 مقاتلو الشاشة (Screen Fighters)

تطبيق أندرويد بيطلع شخصيتين (خضراء وحمراء) عالشاشة، فوق أي تطبيق فاتحه، وبتتقاتلوا تلقائياً. بتقدر تسحبهم بإيدك، تعطيهم أسلحة مختلفة، وتعطيهم عناصر (علاج/تعزيز سرعة) أثناء المعركة.

⚠️ **تنبيه مهم:** هاد تطبيق شخصي/تجريبي (side-load)، مش من متجر Google Play. لازم تفعّل "تثبيت من مصادر غير معروفة" عشان تنصبه.

---

## 🧠 كيف بيشتغل تقنياً

- **MainActivity**: لوحة تحكم فيها أزرار لاختيار سلاح كل شخصية، إطلاقها، إعطاء عناصر، وإيقاف كل شي.
- **OverlayService**: خدمة foreground بتستخدم صلاحية `SYSTEM_ALERT_WINDOW` عشان ترسم الشخصيات فوق باقي التطبيقات، وفيها:
  - حلقة لعبة (game loop) كل 200 مللي ثانية بتحرك الشخصيات نحو بعض وتحسب الضرر.
  - سحب باللمس (Drag) لكل شخصية.
  - نظام أسلحة: **سيف** (ضرر متوسط، مدى قريب، سرعة عالية) / **مسدس** (ضرر عالي، مدى بعيد) / **درع** (ضرر قليل بس بيقلل الضرر الواصل له للنص).
  - نظام عناصر: **علاج** (+30 صحة) و **تعزيز سرعة**.

---

## 🏗️ طريقة بناء الـ APK (عبر GitHub Actions)

بما إنك عادةً تشتغل من Termux، أسهل طريقة تبني فيها APK كامل هي عبر GitHub Actions (مو محتاج تنزل Android Studio):

1. اعمل مستودع جديد على GitHub (خاص أو عام).
2. ارفع كل ملفات هالمجلد للمستودع:
   ```bash
   cd ScreenFighters
   git init
   git add .
   git commit -m "أول نسخة من مقاتلو الشاشة"
   git branch -M main
   git remote add origin <رابط-المستودع-تبعك>
   git push -u origin main
   ```
3. روح لتبويب **Actions** بالمستودع على GitHub، رح تلاقي workflow اسمه **Build APK** اشتغل تلقائياً.
4. لما يخلص (يأخذ كم دقيقة)، افتح الـ run، وبتلاقي بالأسفل تحت **Artifacts** ملف اسمه `screen-fighters-debug-apk` — حمّله وفكّه (zip) وجوا رح تلاقي `app-debug.apk`.

## 📲 طريقة التثبيت والاستخدام

1. انقل ملف `app-debug.apk` لهاتفك ونصّبه (فعّل "مصادر غير معروفة" إذا طلب منك).
2. افتح التطبيق واضغط **"طلب صلاحية الظهور فوق التطبيقات"** ووافق.
3. اختار سلاح للشخصية الخضراء واضغط **"إطلاق الشخصية الخضراء"**.
4. اختار سلاح للشخصية الحمراء واضغط **"إطلاق الشخصية الحمراء"**.
5. اطلع من التطبيق وافتح أي تطبيق تاني (واتساب، يوتيوب...) — رح تلاقي الشخصيتين عم يتحركوا فوقه ويتقاتلوا تلقائياً.
6. اسحب أي شخصية بإصبعك لتحريكها يدوياً.
7. رجع لتطبيق "مقاتلو الشاشة" بأي وقت وأعطيهم علاج أو تعزيز سرعة وانت بالمعركة.
8. لما تخلص، اضغط **"إيقاف كل الشخصيات"**.

---

## 🔧 أفكار للتوسيع مستقبلاً

- إضافة رسوم متحركة حقيقية (Sprite animation) بدل الإيموجي الثابت.
- إضافة أصوات ضرب/موت.
- المزيد من الأسلحة والعناصر (ترس دفاعي مؤقت، قنبلة منطقة).
- إمكانية اختيار عدد شخصيات أكتر من 2.
- حفظ الإحصائيات (كم مرة فاز كل لون) بملف محلي.

هاد المشروع مبني كنقطة انطلاق كاملة وشغالة — عدّل عليه براحتك حسب أفكارك.
